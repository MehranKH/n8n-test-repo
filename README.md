# فرم ورود — Digdesign

یک فرم ورود ساده و فارسی (RTL) ساخته‌شده با کامپوننت‌های دیزاین‌سیستم **Digdesign**. این فرم به کاربر اجازه می‌دهد با شماره موبایل و رمز عبور وارد حساب کاربری شود و مسیرهای فرعیِ رایج (فراموشی رمز و ثبت‌نام) را در اختیار او می‌گذارد.

## محصول

- **چه چیزی است؟** یک کامپوننت فرم ورود (`LoginForm`) در `components/login-form.tsx`.
- **چه مشکلی را حل می‌کند؟** نقطهٔ ورود استاندارد و دسترس‌پذیر برای احراز هویت کاربران را فراهم می‌کند تا هر صفحهٔ ورود در پروژه از یک ظاهر و رفتار یکسان پیروی کند.
- **کاربر چه کاری می‌تواند انجام دهد؟** شماره موبایل و رمز عبورش را وارد کند، گزینهٔ «مرا به خاطر بسپار» را انتخاب کند، به صفحهٔ فراموشی رمز برود و فرم را با دکمهٔ «ورود به حساب» ثبت کند.
- **جریان اصلی:** پر کردن شماره موبایل ← پر کردن رمز عبور ← (اختیاری) انتخاب «مرا به خاطر بسپار» ← کلیک روی «ورود به حساب». اعتبارسنجیِ خالی‌بودنِ فیلدها با `required` و اعتبارسنجی بومی مرورگر انجام می‌شود.

## کامپوننت‌های استفاده‌شده

| کامپوننت | چرا انتخاب شده |
| --- | --- |
| `Card` (با Header/Title/Description/Content/Footer) | ظرف ساختارمند و خوانا برای فرم که سرصفحه، بدنه و پاصفحه را از هم جدا می‌کند. |
| `TextField` | فیلد شماره موبایل با برچسب، اتصال خودکار `aria` و پشتیبانی داخلی از ارقام فارسی (کاربر فارسی تایپ می‌کند، فرم مقدار لاتین می‌گیرد). |
| `PasswordField` | فیلد رمز عبور با دکمهٔ نمایش/پنهان‌کردن داخلی — دقیقاً همان چیزی که فرم ورود نیاز دارد، بدون کد اضافه. |
| `Checkbox` + `Label` | گزینهٔ اختیاری «مرا به خاطر بسپار» با برچسب قابل‌کلیک و دسترس‌پذیر. |
| `Link` | لینک‌های فرعی «فراموشی رمز عبور؟» و «ثبت‌نام کنید». |
| `Button` | دکمهٔ اقدام اصلی «ورود به حساب» به‌صورت تمام‌عرض با حالت بارگذاری (`loading`) هنگام شبیه‌سازی ارسال. |

## آیکون‌ها

در این فرم نیازی به استفاده از آیکون جداگانه نبود. تنها آیکون‌هایی که دیده می‌شوند (چشمِ نمایش/پنهان‌کردن رمز و تیکِ چک‌باکس) به‌صورت داخلی در خودِ کامپوننت‌های `PasswordField` و `Checkbox` پیاده‌سازی شده‌اند.

## نصب و استفاده

این کامپوننت برای پروژه‌ای نوشته شده که کامپوننت‌های Digdesign را نصب دارد (آلیاس `@/components/ui/...` و `@/lib/utils`). کامپوننت‌های لازم با رجیستری Digdesign نصب می‌شوند:

```bash
# نصب کامپوننت‌های موردنیاز از رجیستری Digdesign
npx dig add card text-field password-field checkbox label link button
```

سپس `LoginForm` را در هر صفحه ایمپورت کنید:

```tsx
import { LoginForm } from "@/components/login-form"

export default function LoginPage() {
  return (
    <main className="flex min-h-screen items-center justify-center bg-muted p-4">
      <LoginForm />
    </main>
  )
}
```

> نکته: هندلر ارسال فعلاً فقط حالت بارگذاری را شبیه‌سازی می‌کند؛ در پروژهٔ واقعی، درخواست ورود به سرور در `handleSubmit` جایگزین می‌شود.
