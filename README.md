# دکمهٔ تایید بدون آیکون (Confirm Button)

یک دکمهٔ تایید ساده و تمیز برای فرم‌ها که **بدون هیچ آیکونی** ساخته شده است.

## کامپوننت‌های استفاده‌شده

- **Button** (کامپوننت `button` دیزاین‌سیستم دیگ) با تنظیمات:
  - واریانت: `default`
  - رنگ: `primary` (توپُر با کنتراست مناسب برای کنش اصلی فرم)
  - اندازه: پیش‌فرض
  - `type="submit"` برای نقش تایید/ثبت در فرم

## چرا بدون آیکون؟

کاربر صریحاً «دکمه تایید بدون آیکون» را خواسته بود؛ بنابراین هیچ آیکونی از مجموعهٔ آیکون‌های دیگ انتخاب نشد تا دکمه دقیقاً مطابق درخواست، فقط با متن «تایید» باقی بماند.

## استفاده

```tsx
import { ConfirmButton } from "@/components/confirm-button"

<form>
  {/* سایر فیلدهای فرم */}
  <ConfirmButton />
</form>
```
